# Security & Responsible Use Policy

## Architecture

The Auracelle platform landing page is a **fully static HTML file**. It operates with:

- No backend server or database
- No user authentication or accounts
- No data collection, cookies, or analytics
- No external API calls at runtime
- All content rendered client-side in the browser

The only external resources loaded are Google Fonts (via CDN) for typography.
